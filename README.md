# Splash Zone — Battleship

Two-player Battleship for phones, played in the browser.

**Play:** https://jerridthomas-79.github.io/splashzone/

1. Player 1 taps **Start a game** and gets a 4-letter code (or shares the invite link).
2. Player 2 taps **Join game** and enters the code.
3. Both place ships, tap **Ready!**, and take turns firing.

Solo? Tap **Play vs Computer** for a 2-round practice match against an AI opponent.

Phones connect directly to each other with WebRTC (via PeerJS), so there's no server to run — GitHub Pages hosts the page and the free PeerJS service just introduces the two phones.
